Installation and configuration

Project overview · Install · Import · DNS · Update

Install

Requirements: macOS 14.4+, Apple Command Line Tools, Homebrew and access to an AnyConnect-compatible gateway. The installer offers missing tools.

$install_command

Run as your regular user. The command downloads source from GitHub and builds it on your Mac. Installing the system helper requires administrator access. System setup may interrupt an existing VPN session.

Import a profile

Double-click a received .ocmac file or choose Open profile… in the app. Check the gateway and your username, then connect.

ocmac import work.ocmac
ocmac profile-check work.ocmac
ocmac connect work

One .ocmac file describes one connection: address, routes, DNS, form rules and optional CSD. Cisco XML imports server addresses; configure routes and DNS for those entries separately.

Opening a file does not execute its CSD or credential commands. Connecting may execute them: use configuration from a trusted sender.

Create a profile

Create ~/.config/ocmac/profiles/work.ocmac using the example. Set the gateway, username, required networks and DNS domains. Password and TOTP secret values do not belong in the file.

ocmac profile-check ~/.config/ocmac/profiles/work.ocmac
ocmac connect work --teach

Complete your organization’s sign-in. After successful authentication, you can save form rules, a password in Keychain and the one-time code source. Saving the profile itself does not save a password.

Routes and DNS

[Routes] lists IPv4 networks to send through the tunnel. [DNS] lists entries such as corp.example.com = vpn. The vpn value uses a resolver supplied by the gateway. Each domain includes its subdomains; a more specific DNS zone takes priority.

A search suffix, DNS server addresses and a split-DNS list are different settings. A suffix alone does not describe the gateway’s full DNS policy. List required domains explicitly; other names use the normal DNS connection.

HostScan / CSD

If your gateway requires device assessment, obtain an organization-approved wrapper. Profiles support CsdWrapper for a local file or CsdScriptBase64 for an embedded script. See INSTALL.md (Russian) for details.

ocmac prepare
sudo ocmac install
ocmac csd-status work

An embedded CSD script still needs its system copy installed. csd-status compares the contents. The example wrapper in the repository is not a device assessment ready for deployment.

Connection recovery

ocmac autoconnect resume
ocmac pause
ocmac resume
ocmac disconnect

autoconnect resume restores the last selected connection. manual disables fresh automatic sign-ins. Pause retains the session while removing the app’s routes and DNS settings. Explicit Disconnect clears the selected connection. Expired authentication may require signing in again.

Update

brew upgrade openconnect-for-mac
ocmac app upgrade
ocmac doctor

If diagnostics report an outdated helper, repeat ocmac prepare && sudo ocmac install. System changes may interrupt your current VPN.

Share a profile

ocmac export work team.ocmac

Before sharing, review User, local paths, CSD and custom commands. Export does not retrieve credential-store secrets. Share corporate addresses and settings within your team.

Diagnostics

ocmac status --json
ocmac doctor
ocmac logs -n 100
ocmac report report.txt

Troubleshooting. Before publishing a report, check it for gateway addresses, usernames, cookies and tokens.

Uninstall

sudo ocmac uninstall
brew uninstall openconnect-for-mac

Remove the system helper before the Homebrew package. Profiles, logs, WebKit data and Keychain entries remain. Full cleanup is documented in INSTALL.md (Russian).
