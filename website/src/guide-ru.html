Установка

Требования: macOS 14.4+, инструменты Apple Command Line Tools, Homebrew и доступ к AnyConnect-совместимому шлюзу. Недостающие инструменты предложит установщик.

$install_command

Запускайте от обычного пользователя. Команда загружает исходники с GitHub и собирает их на Маке. Для установки системного помощника потребуется пароль администратора. Системная установка может прервать прежнюю VPN-сессию.

Импорт профиля

Откройте полученный .ocmac двойным щелчком или через «Открыть профиль…» в приложении. Проверьте адрес и свой логин, затем подключитесь.

ocmac import work.ocmac
ocmac profile-check work.ocmac
ocmac connect work

Один .ocmac содержит одно подключение: адрес, маршруты, DNS, правила входа и необязательный CSD. Cisco XML импортирует список серверов; сети и DNS для этих записей нужно настроить отдельно.

Открытие файла не исполняет его CSD или команды получения секретов. При подключении они могут выполняться: используйте конфигурацию от доверенного отправителя.

Новый профиль

Создайте ~/.config/ocmac/profiles/work.ocmac по образцу. Укажите адрес шлюза, логин, нужные сети и DNS-домены. Пароль и TOTP-секрет в файл не записываются.

ocmac profile-check ~/.config/ocmac/profiles/work.ocmac
ocmac connect work --teach

Войдите в форме организации. После успешного входа можно сохранить правила формы, пароль в связку ключей и источник одноразового кода. Само сохранение профиля не сохраняет пароль.

Маршруты и DNS

В [Routes] перечисляются IPv4-сети в туннель. В [DNS] — домены вида corp.example.com = vpn. Значение vpn берёт резолвер из ответа шлюза. Домен включает поддомены; более длинная DNS-зона имеет приоритет.

Поисковый суффикс, DNS-серверы и список split-DNS — разные параметры. По одному суффиксу нельзя определить полную DNS-политику шлюза. Добавляйте нужные домены явно; обычный интернет остаётся на обычном DNS.

HostScan / CSD

Если шлюз требует проверку устройства, получите утверждённый организацией wrapper. Профиль поддерживает CsdWrapper с путём к файлу или CsdScriptBase64 со встроенным скриптом. Подробности — в INSTALL.md.

ocmac prepare
sudo ocmac install
ocmac csd-status work

Наличие CSD в профиле не означает, что его системная копия установлена. Проверка csd-status сравнивает содержимое. Пример wrapper в репозитории не является готовой оценкой состояния вашего устройства.

Восстановление соединения

ocmac autoconnect resume
ocmac pause
ocmac resume
ocmac disconnect

autoconnect resume восстанавливает последнее выбранное подключение. Режим manual запрещает новые автоматические входы. Пауза сохраняет сессию без маршрутов и DNS-настроек приложения. Явное отключение сбрасывает выбранное соединение. Истёкшая авторизация может потребовать повторного входа.

Обновление

brew upgrade openconnect-for-mac
ocmac app upgrade
ocmac doctor

Если диагностика сообщает об устаревшем помощнике, повторите ocmac prepare && sudo ocmac install. Системные изменения могут прервать текущий VPN.

Передача профиля

ocmac export work team.ocmac

Перед передачей проверьте User, локальные пути, CSD и пользовательские команды. Экспорт не извлекает секреты из хранилищ. Корпоративные адреса и настройки передавайте внутри команды.

Диагностика

ocmac status --json
ocmac doctor
ocmac logs -n 100
ocmac report report.txt

Разбор типовых проблем. Перед публикацией отчёта проверьте, что в нём нет адресов шлюзов, логинов, cookie и токенов.

Удаление

sudo ocmac uninstall
brew uninstall openconnect-for-mac

Сначала удаляется системный помощник, затем пакет Homebrew. Профили, журналы, данные WebKit и записи связки ключей остаются. Полная очистка описана в INSTALL.md.
